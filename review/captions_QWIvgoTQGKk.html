Caption templates: which ones should we offer?

Each clip shows the same captions in every template (a saved bundle of settings: font, size, colours, outline or box, word highlight, animation, words per line, position; any of these can be changed per user later). Switch between the crop and fit pictures. Under each style press Offer if it is good enough to give users (several can be on), and note anything wrong: size, speed, placement, a wrong line break. Then Download.
